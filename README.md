# GridsApps Bootstrap Starter

Day 06 project: a responsive web page built with Bootstrap 5.3.3.

## Sections

- **Hero:** title, short description, and two buttons.
- **Services:** a responsive card grid (1, 2, or 3 columns depending on screen size).
- **Pricing (B01):** three responsive pricing cards built with the grid and utility classes.
- **Dashboard Summary (B03):** four KPI cards and a summary table.

## Tech Stack

HTML, Bootstrap 5.3.3 (CDN), and a custom stylesheet (`css/custom.css`).

## How to Run

1. Clone or download the repository.
2. Open `index.html` with Live Server or in a browser.
